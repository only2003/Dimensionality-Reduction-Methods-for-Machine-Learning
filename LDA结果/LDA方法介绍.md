# LDA

## 方法介绍

LDA，即线性判别分析（Linear Discriminant Analysis，又称 Fisher 线性判别），其特点是能在使用样本类别标签的前提下进行**监督降维**与**分类**。降维是指不把全部原始特征都拿来建模，而是寻找若干条"判别轴"，将高维样本投影到低维判别空间；分类则是指投影得到的判别轴本身就可以构成线性分类边界。与无监督的 PCA 不同：PCA 不看标签、只保留数据方差最大的方向；LDA 使用标签、追求"**类间距离尽量大、类内离散尽量小**"，因此得到的低维表示对区分不同类别最有意义。

LDA 的目标函数由 Fisher 准则给出：寻找投影方向 w，使

　　J(w) = wᵀS_Bw / wᵀS_Ww

最大化。其中 S_B 为类间散度矩阵（各类均值与总体均值差异的加权），S_W 为类内散度矩阵（各类内部样本相对本类均值的离散程度）。直观理解：分子越大，不同类别的中心在投影方向上拉得越开；分母越小，各类内部越紧凑。

LDA 的降维维数存在数学上限：最多为 min(特征数, 类别数 − 1) 维。**二分类最多只能得到 1 条判别轴（LD1）**，多分类才可能得到多条判别轴。因此本实验数据集（300 个样本 × 50 个特征、二分类标签"品鉴师评分"）最终输出维数为 1，这是理论决定的，不是代码问题。

不论因变量是连续的，还是二元或多元离散的，都可以用 LDA 进行建模预测（离散类别标签是 LDA 的标准适用场景）。由于 LDA 对特征量纲敏感，拟合前必须先做标准化/归一化，否则量纲大的特征会主导判别方向；本实验用 StandardScaler 标准化，且只在训练集上 fit、再转换测试集，避免信息泄漏。

**对本实验结果（lda_result.png）的解读：**

- **一维投影分布（左上）**：类别 0 与类别 1 在 LD1 轴上有明显分离、仅少量重叠，说明二分类样本可被单条判别轴基本分开。
- **判别信息解释率（右上）**：LD1 的解释率达到 100.0%。二分类的全部类间判别信息集中在这 1 条轴上，不存在"取几条轴"的权衡问题，属预期现象。
- **混淆矩阵（左下）**：测试集 60 个样本中 54 个预测正确，准确率 0.9000；类别 0 全部判对（32/32），类别 1 有 6 个被误判为类别 0。
- **LD1 主要载荷（右下）**：贡献最大的原始特征是挥发酸(g/L醋酸)、酒精度(%vol)、总酚(mg/L)、色度(AU)等，说明这些理化指标是区分两类品鉴评分的关键变量。

**降维前后分类效果对比：**

| 方案 | 测试集准确率 |
| --- | --- |
| 原始 50 维 + 逻辑回归 | 0.8833 |
| LDA 降至 1 维 + 逻辑回归 | 0.8667 |
| LDA 自身分类器 | 0.9000 |

用 1 维代替 50 维（降维率 98%），准确率几乎不下降：三者差距仅在 1~2 个样本之间（54/53/52），且 LDA 自身分类器准确率反而最高，说明 LD1 已提取了数据中绝大部分判别信息，降维没有损失有效信息。

而在影像组学等小样本高维场景中（如田捷团队在 JCO 发表的经典工作），LDA 常与 LASSO 等特征筛选手段结合使用：先用 LASSO 筛出关键特征，再对筛选后的特征做 LDA 降维/分类，并通过交叉验证评估稳定性，避免特征数远大于样本数时出现过拟合。
